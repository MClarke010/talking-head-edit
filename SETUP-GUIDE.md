# Edit your talking videos with Claude

**One-time setup, about 10 minutes. After that, every video takes one sentence.**

**Before you start:** a Mac, and a paid Claude plan that includes Claude Code (the **Code** tab in the Claude desktop app).

## 01. Download it from GitHub
No GitHub account needed. Go to **github.com/YOUR-USERNAME/talking-head-edit**, click the green **Code** button, then **Download ZIP**. Double-click the zip to open it. You'll get a folder called **talking-head-edit-main** in your Downloads.

## 02. Open Claude Code
Open the Claude desktop app and click the **Code** tab.

## 03. Install it
Copy and paste this. Claude asks before downloading anything, so say yes. When it's done, start a new session so Claude picks up the skill.

> Install the talking-head-edit skill from the talking-head-edit-main folder in my Downloads into my personal skills (~/.claude/skills), then check and set up the tools it needs.

## 04. Make it yours
Grab **3 to 5 reference photos or videos** of the look you love: your own past posts, or screenshots of captions you wish were yours. Drag them in and say:

> Set up my video style using these references.

Claude studies the fonts, colors, and caption placement, suggests a look, and saves it once you say yes. Every video after this comes out in your style.

## 05. Edit your first video
Drag in a raw video of yourself talking and say **"Edit this video."** Claude cuts it, shows you the cut, then adds your captions, a title, and sound effects. Ask for changes in plain English: "keep the part about my dog," "move the captions up a little."

## Tips
- Film vertical, at eye level, somewhere quiet.
- Your first edit is slower because of the one-time setup. After that, it's quick.
- Every version saves as a new file, so you never lose one you liked.

## If something's off
- **Claude doesn't see the skill:** start a new session in the Code tab.
- **Fonts look different:** use fonts installed on your computer.
